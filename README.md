# MelonVolt v.01

Compact NVIDIA GPU tuning console for GTX 10 and RTX 20–50 series.

## Features

* Clock, voltage, power and fan control
* V/F curve editor
* Live hardware monitoring
* Profiles and global hotkeys
* Startup profiles
* Multi-GPU selection
* Driver, VBIOS and allowed-range status
* Command-line support
* Single portable EXE

* Windows 10 or 11, 64-bit
* Administrator privileges
